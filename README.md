# CASPIAN LOGISTICS — Проект 2 за Цветан

Самостоятелен интерактивен прототип v0.2 на мултимодална платформа за Средния (Транскаспийски) транспортен коридор.

## Отвори сайта

Този репозитори съдържа самостоятелния файл `index.html` — без инсталация, зависимости, компилация или сървър. Отвори го локално в браузър или през GitHub Pages.

## Демо функции

- Планиране на примерни мултимодални маршрути.
- Борса за товари: нови заявки, търсене, филтриране, редактиране/изтриване, локален експорт на JSON.
- Демонстрационно проследяване по логистични етапи.
- Контролен списък за транспортни и митнически документи.
- Категории партньори, превозвачи и терминали.
- Responsive интерфейс за компютър и телефон.

## Важно

**Това е демонстрационен прототип, не действаща транспортна платформа.**

Данните и примерните товари не са реални. Данните се съхраняват локално в браузъра. Не се изпращат транспортни заявки, не се извършват фериботни резервации, не се създават правно валидни e-CMR/e-TIR документи и не се използва реално GPS проследяване.

Разработката е **изцяло независима от Проект 1 — TRADE-TSVETAN и Grupaj.bg**. Не се променят никакви съществуващи системи.

## Следващи етапи

Отделна сървърна база данни, фирмени регистрации и роли, административен панел, валидиране на оператори, сигурно управление на файлове, API интеграции с транспортни оператори, реално проследяване и резервации след проверка на възможните партньорства.

Последна версия: 0.2 (23 ноември 2026).
