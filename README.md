# CASPIAN LOGISTICS — Проект 2 за Цветан

Самостоятелен интерактивен прототип v0.2 на мултимодална платформа за Средния (Транскаспийски) транспортен коридор.

## Отвори сайта

Този репозитори съдържа самостоятелния файл `index.html` — без инсталация, зависимости, компилация или сървър. Отвори го локално в браузър или през GitHub Pages.

## Демо функции

- Планиране на примерни мултимодални маршрути.
- Борса за товари: нови заявки, търсене, филтриране, редактиране/изтриване, локален експорт на JSON.
- Демонстрационно проследяване по логистични етапи.
- Контролен списък за транспортни и митнически документи.
- Категории партньори, превозвачи и терминали.
- Responsive интерфейс за компютър и телефон.

## Важно

**Това е демонстрационен прототип, не действаща транспортна платформа.**

Данните и примерните товари не са реални. Данните се съхраняват локално в браузъра. Не се изпращат транспортни заявки, не се извършват фериботни резервации, не се създават правно валидни e-CMR/e-TIR документи и не се използва реално GPS проследяване.

Разработката е **изцяло независима от Проект 1 — TRADE-TSVETAN и Grupaj.bg**. Не се променят никакви съществуващи системи.

## Следващи етапи

Отделна сървърна база данни, фирмени регистрации и роли, административен панел, валидиране на оператори, сигурно управление на файлове, API интеграции с транспортни оператори, реално проследяване и резервации след проверка на възможните партньорства.

## Ново във версия 0.3 — Milestone Tracking (24 ноември 2026)

- [Отвори новия модул](./tracking.html) — разширена история на събитията, търсене, преглед на етапи, източници, демонстрационно забавяне, локално добавяне на тестови събития и JSON експорт.
- **Демо на GitHub Pages**: [Milestone Tracking](https://dnchcoin.github.io/CASPIAN-LOGISTICS/tracking.html).
- **Отделен локален API сървър** с SQLite, запис и идемпотентно приемане на събития, SSE поток и удостоверяване за промени. Стартира с Node 24+: `node tracking-api/server.mjs`.
- **Автоматизирани API тестове**: `node --test tracking-api/test.mjs`.
- Пълна спецификация, ограничения и път към интеграции: [docs/TRACKING-MILESTONES.md](./docs/TRACKING-MILESTONES.md).

**Реални операторски интеграции все още няма.** Публичният GitHub Pages използва само демонстрационни данни. Локалният API не трябва да се излага публично без автентикация за четене, права за организации и допълнителни проверки за сигурност.

## Данни v0.4 — PostgreSQL основа

Изолирана PostgreSQL схема с 9 таблици за фирми, потребители, роли, заявки, пратки, маршрути, събития, документи и журнал. Миграцията и фирмената изолация са проверени с PostgreSQL 17. **Все още няма постоянна база, достъпна от публичния сайт.** [Инструкции за базата](./db/README.md).

Последен функционален модул: Milestone Tracking v0.3; подготвена база данни v0.4 (24 ноември 2026).
